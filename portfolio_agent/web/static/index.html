Verification codes by email

For logins whose code arrives by email (two-step code: email). The fetcher reads the code from Gmail, read-only: only messages that arrive after it asks for a code and that come from the login's own site (or its code sender). Messages stay unread and nothing is stored. Needs a Google app password: Google Account → Security → 2-Step Verification → App passwords. Without this, the Inbox asks you for the code.

Part-owned entities

For accounts held by an entity you own part of, such as an LLC. Add the entity and your percentage here, then pick it under Owned by for each of its accounts (open the login with Edit). Those accounts, including the entity's loans and cards, count at your percentage in net worth and the chart; their stored values and View Source stay as the portal shows them. A change of percentage applies from its date, so earlier months keep the old one; the first percentage also covers earlier history.
